# XDWarp
Make Scratch Projects Locally!

This Scratch Mod is based off Scrooch 3 and runs fully local; which means you are running a entire project editor under than 1 gigabytes fully locally,inside your own computer! Try it out today!

# How to download
To download XDWarp into your computer,you must go to releases and pick a version,then select code and press download zip!
After that,extract the .zip folder of the release you just have downloaded and then extract it. Then,you should press "Start XDwarp" shortcut or open "index.html"! After that steps,enjoy your project editor!

# Fix glitches
If you see that the project canvas did not load or had any errors,just reload the page! Then u will see it working properly.
